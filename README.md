# 📈 محلل الأسهم الذكي — AI Stock Analyzer

تطبيق ويب لتحليل الأسهم بالذكاء الاصطناعي، مبني بملف `index.html` واحد **بدون أي اعتماديات خارجية** — يعمل مباشرة على GitHub Pages أو بفتح الملف في المتصفح.

## ✨ المميزات

- 🕯️ **شارت تفاعلي**: شموع يابانية (Candlesticks) + حجم التداول + خطوط SMA20/SMA50 + نطاق Bollinger
- 📊 **مؤشرات فنية محسوبة تلقائيًا**: RSI(14) · MACD(12,26,9) · ATR(14) · Bollinger Bands · متوسطات متحركة
- 🧠 **محرك توصيات مدمج**: يحلل 6 مجموعات من الإشارات ويولّد توصية (شراء قوي → بيع قوي) مع نسبة ثقة وأسباب مفصلة
- 🎯 **مستويات متقدمة**: دعم ومقاومة، وقف خسارة مقترح، هدف أول
- 🤖 **تحليل بالذكاء الاصطناعي الحقيقي (اختياري)**: اربط أي مزوّد متوافق مع OpenAI API (OpenAI، Mistral، Groq، OpenRouter، Ollama...) ليكتب النموذج تقريرًا احترافيًا كاملًا
- 📥 **استيراد CSV**: حلّل بياناتك الحقيقية من Yahoo Finance أو أي مصدر بصيغة `Date,Close,High,Low,Open,Volume`
- 🇪🇬 واجهة عربية كاملة (RTL) مع بيانات تجريبية لأسهم أمريكية ومصرية

## 🚀 التشغيل

### الطريقة 1: مباشرة
نزّل `index.html` وافتحه في المتصفح.

### الطريقة 2: GitHub Pages
1. اعمل Fork أو انسخ هذا الريبو إلى حسابك
2. **Settings → Pages**
3. اختر Branch: `main` / `root` ثم Save
4. بعد دقيقة ستجد التطبيق على: `https://<username>.github.io/ai-stock-analyzer/`

## 🤖 تفعيل تحليل الـ AI الحقيقي

1. اضغط زر **«تحليل بالـ AI حقيقي»**
2. أدخل:
   - **Base URL**: مثلًا `https://api.openai.com/v1` أو `https://api.mistral.ai/v1` أو `https://api.groq.com/openai/v1`
   - **API Key**: مفتاحك
   - **Model**: مثلًا `gpt-4o-mini` أو `mistral-small-latest`
3. سيُرسل التطبيق لقطة المؤشرات المحسوبة للنموذج ويكتب تقريرًا احترافيًا بالعربية

> المفتاح يُخزَّن في متصفحك فقط (localStorage) ولا يُرسل لأي طرف آخر.

## ⚠️ إخلاء مسؤولية

هذا المشروع لأغراض **تعليمية** فقط. البيانات الافتراضية **بيانات محاكاة** وليست أسعارًا حقيقية، والتوصيات المولَّدة ليست نصيحة استثمارية. لا تتخذ أي قرار مالي بناءً على هذا التطبيق دون استشارة مالية مرخصة.
