# 🕌 عقار — محلل البورصة المصرية بالذكاء الاصطناعي

تطبيق ويب شخصي لتحليل **البورصة المصرية (EGX)** بالذكاء الاصطناعي — ملف `index.html` واحد بدون أي اعتماديات، يعمل على GitHub Pages مباشرة.

> للاستخدام الشخصي · واجهة عربية بالكامل (RTL) · بياناتك محفوظة في متصفحك فقط

## ✨ المميزات

### 📡 أسعار حقيقية شبه لحظية — مجانًا وبدون أي مفتاح API
- **101 سهم مصري** برموزها وأسمائها العربية وقطاعاتها (EGX100 + الشركات الإضافية الرئيسية)
- جلب البيانات من **Yahoo Finance** (لاحقة `.CA`) عبر سلسلة من 7 بروكسيات مجانية احتياطية (مباشر → AllOrigins → corsproxy.io → codetabs → ...)
- **لقطة أسعار مدمجة** من إغلاق آخر جلسة تعمل عند تعذر الاتصال + تخزين مؤقت ذكي (10 دقائق للأسعار / 12 ساعة للتاريخ)
- **🩺 تشخيص مصادر الأسعار**: زر في الإعدادات يفحص كل البروكسيات ويوضح أي واحد يعمل عندك

### 🧠 محرك التوصيات الذكي
- تقييم كل سهم على **6 محاور**: الاتجاه (SMA20/50) · الزخم (RSI) · MACD · بولنجر · سلوك الحجم · الموقع من مدى 52 أسبوعًا
- توصية واضحة (شراء قوي → بيع قوي) + **نسبة ثقة** + تقييم بالنجوم + مستويات **دعم/مقاومة/وقف خسارة/هدف أول**
- **🌟 توصيات اليوم**: ماسح ذكي يفحص ~40 سهمًا من الأكثر سيولة ويرتّب أقوى الفرص وأهم التحذيرات

### ☪️ قسم الشريعة — مؤشر EGX33 الرسمي
- قائمة الأسهم المتوافقة مع الشريعة (مكونات EGX33 من البورصة المصرية)
- **نسب التطهير** التقديرية لكل سهم + حاسبة تطهير جاهزة
- فلتر «متوافق مع الشريعة فقط» في كل الجداول

### 💼 محفظتي
- أدخل أسهمك (الكمية + متوسط الشراء) — يعمل تلقائيًا: **الربح/الخسارة** لكل سهم وللمحفظة كلها
- **قرار AI لكل سهم**: احتفاظ / زيادة بحذر / جني أرباح / بيع — بناءً على التحليل الفني **وموقفك الربحي معًا**
- 🏦 **صناديق الاستثمار**: تتبع يدوي (وحدات + متوسط شراء + آخر NAV من كشف حسابك) بحساب الأداء تلقائيًا

### 🤖 ربط نموذج ذكاء اصطناعي حقيقي (اختياري)
من **الإعدادات** اختر المزوّد من قوالب جاهزة (Mistral · Groq · OpenAI · OpenRouter · Ollama) — اضغط الرابط بجانب خانة المفتاح للحصول عليه، الصقه، ثم **🧪 اختبار الاتصال**:
- تقرير سرد احترافي لأي سهم من مؤشراته الفعلية
- **تحليل المحفظة كاملة**: قرارات احتفاظ/زيادة/بيع لكل سهم
- ملخص جلسة السوق

> المفتاح يُخزَّن في متصفحك (localStorage) ولا يغادر جهازك. الأسعار الحقيقية **لا تحتاج أي مفتاح**.

## 🚀 التشغيل — 3 طرق

### الطريقة 1: GitHub Pages (الأفضل والأسهل)
1. **Settings → Pages**
2. **Source:** Deploy from a branch → **Branch:** `main` / `root` → Save
3. بعد دقيقة: `https://<username>.github.io/ai-stock-analyzer/`

### الطريقة 2: مباشرة على جهازك
نزّل `index.html` وافتحه في المتصفح — بدون تثبيت أي شيء.

### الطريقة 3: Streamlit Cloud
الريبو يتضمن `streamlit_app.py` (غلاف يعرض التطبيق داخل صفحة Streamlit) و`requirements.txt`:
1. ارفع الريبو إلى [share.streamlit.io](https://share.streamlit.io)
2. **Main file path:** `streamlit_app.py` → Deploy
3. سيظهر التطبيق كاملًا داخل الصفحة

> محليًا: `pip install -r requirements.txt` ثم `streamlit run streamlit_app.py`

## 📖 طريقة الاستخدام (راجعة سريعة)
1. افتح تبويب **الأسهم** → اضغط أي سهم → تشوف الشارت والتحليل الفني والتوصية فورًا
2. اضغط **💼 أضف إلى محفظتي** لكل سهم تمتلكه وأدخل الكمية ومتوسط الشراء
3. من تبويب **محفظتي** راجع قرارات الـ AI لكل سهم: احتفاظ / زيادة / بيع
4. تبويب **توصيات اليوم** → **⚡ ابدأ فحص السوق** (مرة واحدة يوميًا تكفي — النتائج تُخزَّن)
5. من **الإعدادات** فعّل الربط بنموذج AI حقيقي + التحديث التلقائي للأسعار

## ⚠️ إخلاء مسؤولية

- البيانات من مصادر مجانية (Yahoo Finance عبر بروكسيات عامة) — **قد تتأخر 15 دقيقة أو تختلف عن سعر السوق الفعلي**
- التوصيات مولَّدة حسابيًا من مؤشرات فنية — **ليست نصيحة استثمارية بأي حال**
- نسب التطهير تقديرية من أحدث القوائم المالية المتاحة — راجع دائمًا [صفحة EGX33 الرسمية](https://www.egx.com.eg/ar/currentindexconstituntes.aspx?type=22&nav=22)
- أنت وحدك المسؤول عن قراراتك المالية
